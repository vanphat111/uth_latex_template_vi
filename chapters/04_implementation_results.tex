\section{Hiện thực mã nguồn}
\label{sec:code_details}

Đoạn mã mẫu cài đặt hàm tính toán bằng Python được minh họa tại Đoạn mã~\ref{lst:sample_code}.

\begin{lstlisting}[language=Python, caption={Đoạn mã minh họa thuật toán xử lý}, label={lst:sample_code}]
def compute_metrics(data_samples, threshold=0.5):
    """
    Ham danh gia chi so phan loai.
    """
    results = []
    for sample in data_samples:
        score = sample.get("score", 0.0)
        is_positive = score >= threshold
        results.append({"id": sample["id"], "prediction": is_positive})
    return results

if __name__ == "__main__":
    test_data = [{"id": 1, "score": 0.82}, {"id": 2, "score": 0.35}]
    print(compute_metrics(test_data))
\end{lstlisting}
